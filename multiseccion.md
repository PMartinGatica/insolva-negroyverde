# OBJETIVO GENERAL

Tu trabajo NO es crear un proyecto nuevo desde cero sin mirar lo existente.

Primero tenés que:

1. inspeccionar toda la carpeta actual;
2. entender la arquitectura;
3. detectar el stack utilizado;
4. identificar componentes existentes;
5. identificar estilos globales;
6. identificar imágenes y assets;
7. identificar navegación y enlaces;
8. detectar qué partes pueden reutilizarse;
9. detectar problemas de diseño, estructura, responsive o código;
10. recién después comenzar la reconstrucción.

La web debe reconstruirse **por secciones**, manteniendo el proyecto funcional en todo momento.

No destruyas una implementación funcional solamente porque quieras reemplazarla por otra tecnología.

No migres de framework, CMS o arquitectura salvo que sea estrictamente necesario.

Si el proyecto utiliza WordPress, Blocksy, HTML, CSS, JavaScript, PHP u otra tecnología, primero adaptate a la arquitectura existente.
